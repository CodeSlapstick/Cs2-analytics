# เว็บ CS2 Analytics — Frontend + Backend (ล็อกอินด้วย Steam)

ธีมน้ำเงิน-ส้ม · FastAPI (หลังบ้าน) + HTML/CSS/JS ล้วน (หน้าบ้าน) · ไม่ต้องลง Node.js

---

## รันยังไง

```bash
# 1) ลงไลบรารีที่ต้องใช้ (ครั้งแรกครั้งเดียว)
pip install -r requirements.txt

# 2) ตั้งค่า (จะข้ามก็ได้ เพราะมีค่าเริ่มต้นให้แล้ว)
copy .env.example .env      # Windows
# cp .env.example .env      # macOS / Linux

# 3) รันเซิร์ฟเวอร์
python -m uvicorn frontend.app:app --reload
```

เปิดเบราว์เซอร์ที่ **http://localhost:8000**

- ยังไม่มีกุญแจ Steam API → ใช้ปุ่ม **"เข้าใช้งานแบบทดสอบ"** (เติมเลข SteamID64 ไว้ให้แล้ว)
- มีกุญแจแล้ว → ใส่ใน `.env` ที่รากโปรเจกต์ ช่อง `STEAM_API_KEY` แล้วกดปุ่มส้ม **"เข้าสู่ระบบด้วย Steam"**
  (ขอกุญแจฟรีที่ https://steamcommunity.com/dev/apikey)

> `--reload` = แก้โค้ดแล้วเซิร์ฟเวอร์รีสตาร์ตเองอัตโนมัติ ใช้ตอนพัฒนาเท่านั้น

## ล็อกอิน Steam ทำงานยังไง (เล่าเป็นเรื่อง)

Steam ใช้มาตรฐานชื่อ **OpenID 2.0** — จุดสำคัญคือ **เว็บเราไม่เคยเห็นรหัสผ่านของผู้ใช้เลย**

```
ผู้ใช้กดปุ่มส้ม
   │
   ▼
[1] GET /auth/steam/login          เว็บเราสร้างลิงก์แล้วเด้งผู้ใช้ไป steamcommunity.com
   │
   ▼
[2] ผู้ใช้กรอกรหัสที่ Steam        (รหัสอยู่กับ Steam ไม่ผ่านเราเลย)
   │
   ▼
[3] GET /auth/steam/callback       Steam ส่งผู้ใช้กลับมาพร้อม "ใบเสร็จ" ต่อท้าย URL
   │
   ▼
[4] เว็บเราโทรกลับไปถาม Steam      "ใบเสร็จนี้เธอออกเองจริงไหม?"  → ตอบ is_valid:true
   │
   ▼
[5] แกะเลข SteamID64 → ออกคุกกี้ที่เซ็นชื่อไว้ → เด้งเข้า /main
```

**ทำไมต้องมีขั้น [4]?** เพราะข้อมูลที่ต่อท้าย URL ใครก็พิมพ์ปลอมได้
ถ้าเชื่อทันที คนอื่นจะสวมรอยเป็นใครก็ได้ ขั้นนี้คือการโทรเช็กกับต้นทาง

**คุกกี้ปลอมได้ไหม?** ไม่ได้ เพราะเราเซ็นชื่อกำกับด้วย `SECRET_KEY` (ไลบรารี `itsdangerous`)
ถ้ามีคนแอบแก้เลข SteamID ในคุกกี้ ลายเซ็นจะไม่ตรง เซิร์ฟเวอร์จะถือว่า "ยังไม่ล็อกอิน"

## เส้นทาง (routes) ทั้งหมด

| วิธี | เส้นทาง | ทำอะไร |
|---|---|---|
| GET | `/` | หน้าล็อกอิน |
| GET | `/main` | หน้าหลัก |
| GET | `/auth/steam/login` | เด้งไปล็อกอินที่ Steam |
| GET | `/auth/steam/callback` | รับผลจาก Steam แล้วออกคุกกี้ |
| POST | `/auth/dev-login` | ล็อกอินโหมดทดสอบด้วย SteamID64 |
| POST | `/auth/logout` | ออกจากระบบ (ลบคุกกี้) |
| GET | `/api/me` | ตอนนี้ใครล็อกอินอยู่ |
| GET | `/api/config` | เซิร์ฟเวอร์เปิดโหมดทดสอบไว้ไหม |
| GET | `/api/stats` | สถิติจาก `all_kills_25demos.csv` (ต้องล็อกอินก่อน) |

ลองเล่น API แบบมีหน้าจอกดได้ที่ **http://localhost:8000/docs** (FastAPI สร้างให้ฟรี)

## ภาพโปสเตอร์ฝั่งซ้ายของหน้าล็อกอิน

หน้าล็อกอินแบ่งเป็น 2 ฝั่ง — ซ้ายเป็นภาพโปสเตอร์ ขวาเป็นการ์ดล็อกอิน

ภาพที่ใช้อยู่คือ **`frontend/static/hero.png`** อยากเปลี่ยนเป็นภาพอื่นก็แค่เอาไฟล์ใหม่
ไปทับชื่อเดิม แล้วรีเฟรชหน้าเว็บ ไม่ต้องแก้โค้ดเลยสักบรรทัด
(ถ้าชื่อไฟล์ไม่เหมือนเดิม ให้แก้บรรทัด `url("/static/hero.png")` ใน
[static/style.css](static/style.css) ตามไปด้วย)

มี 2 ชั้นช่วยให้ตัวหนังสืออ่านออกเสมอ ไม่ว่าภาพจะสว่างแค่ไหน
- **ผ้าคลุมดำไล่เฉด** ทับด้านซ้ายของภาพ (ชั้นแรกในบล็อก `.hero`)
- **ขอบขวาจางไปเป็นสีพื้น** (`.hero::after`) ให้ภาพกลืนกับฝั่งการ์ด ไม่ตัดขาดเป็นเส้นตรง

เกร็ดอื่น ๆ
- ถ้าไฟล์ภาพหาย เว็บก็ยังใช้งานได้ปกติ CSS จะตกไปใช้พื้นเข้มชั้นล่างสุดแทน
- อยากซ่อนตัวหนังสือ COUNTER STRIKE 2 ให้ลบบล็อก `.hero-mark` ออกจาก [login.html](login.html)
- ภาพแนวนอนจะถูกครอปซ้าย-ขวา ปรับจุดครอปได้ที่ค่า `46% center` ในบรรทัด
  `background-position` (เลขน้อย = เลื่อนภาพไปทางซ้าย)

## ก่อนเอาขึ้นใช้งานจริง อย่าลืม

1. ตั้ง `SECRET_KEY` เป็นค่าสุ่มของตัวเอง (ไม่งั้นล็อกอินหลุดทุกครั้งที่รีสตาร์ต)
2. ตั้ง `ALLOW_DEV_LOGIN=0` เพื่อปิดโหมดทดสอบ (ไม่งั้นใครก็สวมรอยเป็น SteamID ไหนก็ได้)
3. เปลี่ยน `BASE_URL` เป็นโดเมนจริง และใช้ `https://`
4. ถ้าใช้ https แล้ว เพิ่ม `secure=True` ในฟังก์ชัน `make_session_cookie` ของ [app.py](app.py)

09 · USER SCENARIO
ทีมสมัครเล่นที่ไม่มีนักวิเคราะห์

หนึ่งคืนหลังซ้อม — ตั้งแต่ลากไฟล์จนได้ข้อสรุป

ขั้นที่ 1สี่ทุ่ม · ซ้อมเสร็จ
โค้ชลากไฟล์เดโมของคืนนี้ทิ้งไว้ในเว็บ แล้วปิดเครื่องกลับบ้าน
ขั้นที่ 2เช้าวันรุ่งขึ้น
เปิดสกอร์บอร์ดขึ้นมา เห็นว่าคนเปิดรอบของทีมตายก่อนบ่อยกว่าที่รู้สึก
ขั้นที่ 3กดเข้าไปดูรอบจริง
เลือกรอบที่เสียคนแรกเร็ว เห็นว่าตายจุดเดิมซ้ำ ๆ ไม่ใช่เรื่องบังเอิญ
ขั้นที่ 4ก่อนซ้อมรอบหน้า
เปิดสถิติรายคนดูว่าเป็นที่คนเดียวหรือทั้งทีม แล้วคุยกันโดยชี้ที่ภาพ
จุดสำคัญคือไม่มีขั้นไหนต้องรอคน — ระบบแกะไฟล์ให้เองตั้งแต่คืนก่อน พอเช้ามาข้อมูลพร้อมใช้แล้ว
